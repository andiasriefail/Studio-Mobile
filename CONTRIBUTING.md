# Contributing

Bug fixes are very welcome. Send them as a pull request with a short description of the problem and how your change fixes it.

## Contribution terms

By submitting a pull request, you confirm that:

- you wrote the code you are submitting, or you have the right to submit it
- your contribution is licensed under the **PolyForm Noncommercial License 1.0.0**, the same license as this project (see [LICENSE](LICENSE))
- the project owner may relicense your contribution together with the rest of the project, including for the project owner's own commercial purposes

Contributions cannot be merged if you do not agree to these terms.

## Before you submit

- One pull request per fix
- Run the unit tests before submitting
- Do not include tokens, keys, or personal data
