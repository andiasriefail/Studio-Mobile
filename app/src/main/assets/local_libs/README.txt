Taruh file toolchain di folder ini SEBELUM membangun Studio Mobile:

  android.jar  (atau android-35.jar, atau platform-35_r02.zip utuh)   -> API default 35
  kotlin-stdlib-2.4.20.jar

Saat app dibuka pertama kali, file ini otomatis dipasang ke files/build-tools/
(platforms/android-35/android.jar dan kotlin-stdlib.jar). Tidak ada tombol, tidak ada unduhan.
Untuk API lain beri nama android-34.jar atau platform-34_r02.zip.
